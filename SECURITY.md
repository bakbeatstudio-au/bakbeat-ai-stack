# Security policy

## Reporting a vulnerability

Please report suspected security vulnerabilities **privately** using GitHub's private vulnerability
reporting for this repository: open the repository's **Security** tab and choose **Report a vulnerability**.

Please do **not** report suspected vulnerabilities in public issues, pull requests or discussions.

A useful report includes the affected commit or version, what you observed, the steps needed to reproduce it
and the impact you expect. Please do not include real API keys, credentials or personal data.

## What to expect

This is an early-stage project maintained on a best-effort basis. No response time, fix timeline or support
level is promised.

## Scope

This policy covers the code in this repository. Vulnerabilities in third-party dependencies or in the OpenAI or
Anthropic services should be reported to their respective maintainers. Security fixes, if any, will generally target the latest available version. Older versions may not receive fixes.
